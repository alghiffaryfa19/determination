# Licence texts

This directory contains the verbatim standard licence texts referenced by
[`../THIRD_PARTY_NOTICES.md`](../THIRD_PARTY_NOTICES.md).

`../LICENSE` is the MIT licence for Determination's original code. It is not a
relicence of third-party source, generated code, or a component carrying its own
copyright/licence header.

Some upstream projects have file-level or non-standard notices. Their original
notice files must travel with their source and binaries in addition to these
standard texts; libhybris, Mesa, KWin, Quickshell, and vendored Wayland protocol
XML are the important examples.
