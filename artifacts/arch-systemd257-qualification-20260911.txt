Failure (stock ALARM rootfs):
- /usr/lib/systemd/systemd 261.2-1-arch as container PID1 exits in <100ms:
  "Failed to determine whether /proc is a mount point: Protocol driver not
  attached" … "Failed to mount API filesystems. Exiting PID 1."

  directory … Protocol driver not attached" for every config lookup.

  unsupported on the 4.14 kernel; Debian's systemd 257 boots fine in the
  same container config. See artifacts/omarchy-alarm/arch-systemd.strace
  (openat+statx STATX_MNT_ID_UNIQUE pattern before each warning).
